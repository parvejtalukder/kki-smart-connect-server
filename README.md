# KKI Smart-Connects Server

Backend for the **KKI Smart Communication System**, a multilingual communication platform for Kavya Kishor International (KKI).

## Features

- User registration & login
- User search
- Preferred language
- AI message translation
- MongoDB
- Ollama Cloud
- Socket.IO real-time communication

## Tech Stack

- Node.js
- Express.js
- MongoDB
- Ollama Cloud
- Socket.IO
